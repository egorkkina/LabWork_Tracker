# 📘 LabWork Tracker

**LabWork Tracker** — это консольное приложение на C#, предназначенное для учёта выполнения лабораторных работ студентами.

## 🧩 Основные функции

- Управление студентами (добавление, редактирование, удаление)
- Управление лабораторными работами
- Учёт выполнения: статус работы, оценки
- Формирование отчётов:
  - По каждому студенту
  - По каждой лабораторной работе

## 📊 Примеры отчётов

- **По студентам:** средний балл, количество сданных и назначенных работ
- **По лабораторным:** процент выполнения, средняя оценка, общее количество студентов
